# Plagiarism-Checker-TSA
📄 Plagiarism Checker using Python

📌 Project Overview

This project compares two pieces of text and calculates their similarity using TF-IDF and Cosine Similarity.

It provides a basic demonstration of how Natural Language Processing (NLP) can be used to identify potentially similar content.

🎯 Objective

To compare two documents or passages and determine how similar their content is.

🛠️ Technologies Used

- Python
- Google Colab
- Scikit-learn
- Natural Language Processing (NLP)
- TF-IDF
- Cosine Similarity

⚙️ How It Works

1. The user enters two texts.
2. The texts are converted into TF-IDF vectors.
3. Cosine Similarity is calculated.
4. The similarity score is converted into a percentage.
5. The result is classified as Very High, High, Moderate, Low, or Very Low Similarity.

🚀 How to Run

1. Open Google Colab.
2. Upload "Plagiarism_Checker.ipynb".
3. Run the cells.
4. Enter the first document.
5. Enter the second document.
6. View the similarity score.

💻 Example

Text 1:

Artificial intelligence is transforming modern technology.

Text 2:

Artificial intelligence is changing modern technology.

The program calculates the similarity between the two texts.

📈 Applications

- Academic document comparison
- Duplicate content detection
- Document comparison
- Content analysis
- Basic plagiarism screening

⚠️ Limitation

This is a basic text similarity demonstration, not a complete plagiarism detection system. It does not search the internet or compare against a large external database.

✅ Conclusion

The project demonstrates how TF-IDF and Cosine Similarity can be used to compare two texts and identify their degree of similarity.
